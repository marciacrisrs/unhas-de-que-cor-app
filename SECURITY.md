# Security Policy

## Supported Versions

Security fixes are applied to the default branch. Older releases may not receive security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature, when available, to provide the details securely.

If private vulnerability reporting is not enabled for this repository, contact the repository owner through GitHub before disclosing the issue publicly.

Please include, when possible:

- A clear description of the vulnerability.
- Steps to reproduce or a minimal proof of concept.
- The affected version, commit, or component.
- The potential impact.
- Any suggested mitigation.

## Disclosure

Please allow reasonable time for investigation, remediation, and release coordination before public disclosure.

We appreciate responsible disclosure and will acknowledge valid security reports when appropriate.
